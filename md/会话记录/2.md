## 审查结论（为什么盘符可能不显示）

1. **前端没有直接过滤盘符的条件判断**：
   - [renderFiles](file:///s:/Code/Go/project/AI-OSS/smart-nas/web/index.html) 中 `sortedFiles()` 只排序不过滤；`isDiskNode` 只控制"是否可勾选/改删"，**不会隐藏行**。
2. **真正的条件 bug**：搜索框残留关键词。点击面包屑"磁盘"/进入目录时**没有清空关键词**，`refresh()` 里的 `atRoot = PARENT===0 && !kw` 会因 `kw` 非空变成 false，于是请求走搜索接口，返回搜索结果而非盘符列表——表现为"没有显示盘符"。已修复：
   - 点击面包屑"磁盘"、点击上级目录、进入文件夹时立即 `$("keyword").value = ""`。
3. **另一高频原因：过期 Token 静默失败**。旧 token 失效时 `/api/files` 返回 401，原逻辑只弹不太显眼的 toast，页面空白像"没有盘符"。已修复：任何 API 401 立即强制登出回登录页；`/api/auth/me` 失败同样回登录页（不再静默继续）。

## 原因：完全离线环境 + 本地 module 缓存缺失

这些库全部都用于**当前这台机器的 Go module 本地缓存（GOMODCACHE）里不存在**，而网络又不可用，所以无法下载引入。

具体过程：

1. **网络不通**：当初尝试 `go get github.com/spf13/viper` 时，解析 `goproxy.cn` 域名失败（DNS 无法解析），证明这台机器处于**完全离线**状态，无法从任何 Go 代理拉取依赖。

2. **你的约束**：你明确要求"如果遇到依赖下载不下来等网络问题，请不要重构代码"——即不允许我删改 `go.mod`/`go.sum` 里已有的依赖，也不允许替换架构。所以唯一的出路就是使用**本地缓存里已有的包 + Go 标准库**实现等价功能。

3. **Go 的模块解析机制**：Go 编译时只会用 `GOMODCACHE`（这里是 `C:\Users\Administrator\go\pkg\mod`）里已缓存的模块。我要给 `go.mod` 新增一个 `require`（如 `gorm.io/gorm`），Go 必须先到缓存/网络找到对应的 ziphash 校验和在 `go.sum` 里，离线 + 未缓存 = 直接失败。
